1️⃣ Registers الأساسية - 8086

الـ Register ببساطة مكان صغير جدًا وسريع جوه المعالج بيخزن قيمة مؤقتة.

الـ Registers الأساسية:

AX
BX
CX
DX

وكل واحد فيهم 16-bit.

مثال: 
MOV AX, 1234h

يعني:

AX ┌────────────────┐ │ 1234h │ └────────────────┘ 16 bit

2️⃣ AH و AL - تقسيم الـ Register

الـ AX نفسه 16-bit، ممكن نقسمه لنصفين:

AX ┌────────┬────────┐ │ AH │ AL │ │ 8 bit │ 8 bit │ └────────┴────────┘
مثال: 
MOV AX, 1234h

يبقى:

AH = 12h
AL = 34h

ونفس الفكرة تنطبق على الـ Registers الأخرى:

BX → BH + BL
CX → CH + CL
DX → DH + DL

3️⃣ Segment Registers

دي نقطة مهمة جدًا في 8086. عندنا أربعة Segment Registers:

CS → Code Segment
DS → Data Segment
SS → Stack Segment
ES → Extra Segment

فكر فيها كأن الذاكرة متقسمة لمناطق:

Memory │ ├── Code Segment │ ↑ │ CS │ ├── Data Segment │ ↑ │ DS │ ├── Stack Segment │ ↑ │ SS │ └── Extra Segment ↑ ES

🔷 CS - Code Segment

بيحدد المكان اللي فيه الكود/التعليمات. الـ CPU لما ينفذ instruction، بيستخدم CS مع IP للوصول للتعليمة.

🔷 DS - Data Segment

غالبًا بيستخدم للوصول للـ Data.

🔷 SS - Stack Segment

خاص بالـ Stack (عشان PUSH و POP).

4️⃣ التعليمات الأساسية

📌 MOV - نقل البيانات

MOV معناها انسخ قيمة من مكان لمكان.

مثال: 
MOV AX, 10
MOV BX, AX

النتيجة:
AX = 10
BX = 10

📌 ADD - الجمع

مثال: 
MOV AX, 10
ADD AX, 5

النتيجة:
AX = 15

📌 SUB - الطرح

مثال: 
MOV AX, 20
SUB AX, 5

النتيجة:
AX = 15

📌 INC / DEC - الزيادة والنقصان

INC AX  → AX = AX + 1
DEC AX  → AX = AX - 1

5️⃣ العمليات المتقدمة

📌 MUL - الضرب

⚠️ نقطة مهمة: الضرب بيحتاج عناية خاصة.
مثال 1 - ضرب 8-bit: 
MOV AL, 10
MOV BL, 5
MUL BL

النتيجة:
AX = 50
مثال 2 - ضرب 16-bit: 
MOV AX, 100
MOV BX, 5
MUL BX

النتيجة:
DX:AX = 500
(DX = High bits, AX = Low bits)

📌 DIV - القسمة

مثال: 
MOV AX, 20
MOV BL, 5
DIV BL

النتيجة:
AL = 4 (quotient)
AH = 0 (remainder)

6️⃣ Flags Register

الـ Flags عبارة عن bits بتقولك إيه اللي حصل نتيجة آخر عملية:

ZF → Zero Flag (النتيجة = 0)
SF → Sign Flag (النتيجة سالبة)
CF → Carry Flag (حصل carry)
OF → Overflow Flag (حصل overflow)
مثال: 
MOV AX, 10
SUB AX, 10

النتيجة: AX = 0
بالتالي: ZF = 1

7️⃣ المقارنة والقفزات الشرطية

📌 CMP - المقارنة

CMP AX, BX تعني: AX - BX بدون تخزين النتيجة.

مثال: 
MOV AX, 10
MOV BX, 10
CMP AX, BX

يحدث داخليًا: 10 - 10 = 0
النتيجة: ZF = 1 (متساويين)

📌 القفزات الشرطية

التعليمة المعنى
JE Jump if Equal (اقفز إذا كانوا متساويين)
JNE Jump if Not Equal (اقفز إذا كانوا مختلفين)
JG Jump if Greater (اقفز إذا كان أكبر)
JL Jump if Less (اقفز إذا كان أصغر)
JMP Jump Unconditional (قفزة مطلقة)
مثال - If Statement: 
MOV AX, 10
MOV BX, 10

CMP AX, BX
JE equal

MOV CX, 0
JMP done

equal:
    MOV CX, 1

done:

8️⃣ الحلقات

📌 LOOP مع CX

8086 عنده تعليمة LOOP مرتبطة بـ CX:

مثال: 
MOV CX, 5

again:
    INC AX
    LOOP again

// الحلقة ستتكرر 5 مرات

📌 حلقة بدون LOOP

مثال - While Loop: 
MOV CX, 0

again:
    INC CX
    CMP CX, 5
    JL again

// مثل: while(CX < 5) { CX++; }

9️⃣ Labels

الـ Label مجرد اسم لمكان في الكود لكي نستطيع الرجوع إليه لاحقًا:

مثال: 
start:
    MOV AX, 10

loop_here:
    INC AX
    JMP loop_here

🔟 خدمات DOS - INT 21h

دي من أشهر حاجات DOS Assembly:

MOV AH, service
INT 21h
AH الخدمة الشرح
01h Input character قراءة حرف من لوحة المفاتيح (النتيجة في AL)
02h Print character طباعة حرف واحد (من DL)
09h Print string طباعة نص (نهايته $)
4Ch Exit إنهاء البرنامج
مثال - طباعة حرف: 
MOV DL, 'A'
MOV AH, 02h
INT 21h

// سيطبع: A
مثال - طباعة نص: 
msg DB 'Hello World$'

MOV DX, OFFSET msg
MOV AH, 09h
INT 21h

// سيطبع: Hello World
// لاحظ: $ تحدد نهاية النص

1️⃣1️⃣ مثال شامل

برنامج يقارن بين رقمين: 
.data
msg DB 'Equal$'

.code

MOV AX, @data
MOV DS, AX

MOV AX, 10
MOV BX, 10

CMP AX, BX
JNE not_equal

MOV DX, OFFSET msg
MOV AH, 09h
INT 21h

JMP done

not_equal:

done:
    MOV AH, 4Ch
    INT 21h

شرح الكود:

  1. AX = 10, BX = 10
  2. المقارنة: 10 - 10 = 0 → ZF = 1
  3. JNE: متساويين فلا نقفز
  4. طباعة "Equal"
  5. الخروج من البرنامج
